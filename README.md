# StudentHub

StudentHub is a web-based student academic portal designed to provide
students with a centralized platform for accessing academic and
college-related information.

---

## Project Overview

Students often need to access information such as courses, assignments,
attendance, timetable, and notices from different sources.

StudentHub aims to bring these services together into a single,
organized web portal.

This project is being developed as a semester-long web technology
project.

---

## Problem Statement

The current academic information process may require students to access
multiple sources for different types of information.

StudentHub provides a centralized platform where students can access
important academic information through a simple and structured
interface.

---

## Objectives

- Create a centralized student academic portal.
- Provide clear navigation between different modules.
- Support different user roles.
- Organize academic information into separate modules.
- Maintain a structured and scalable project.
- Use Git and GitHub for version control.
- Develop the project incrementally throughout the semester.

---

## User Roles

### Student

Students can:

- Register and login.
- View their dashboard.
- View their profile.
- View courses.
- View assignments.
- Check attendance.
- View timetable.
- Read notices.
- Contact support.

### Faculty

Faculty members can:

- Login to the portal.
- View their dashboard.
- Manage courses.
- Create and manage assignments.
- Manage attendance.
- Publish academic notices.
- View their profile.

### Administrator

Administrators can:

- Manage student accounts.
- Manage faculty accounts.
- Manage courses.
- Manage notices.
- Manage portal information.
- Monitor the overall system.

## Functional Requirements

### Authentication

- Users shall be able to register.
- Registered users shall be able to login.
- The system shall support different user roles.

### Dashboard

- Users shall be able to access important information from the dashboard.
- The dashboard shall provide links to major modules.

### Profile

- Users shall be able to view their profile information.
- Users shall be able to update relevant profile information.

### Courses

- Students shall be able to view enrolled courses.
- Faculty and administrators shall be able to manage course information.

### Assignments

- Students shall be able to view assignments.
- Students shall be able to view assignment deadlines.
- Faculty shall be able to create and manage assignments.

### Attendance

- Students shall be able to view attendance.
- Faculty shall be able to manage attendance records.

### Timetable

- Students shall be able to view their weekly timetable.

### Notices

- Users shall be able to view academic notices.
- Authorized users shall be able to publish notices.

### Contact

- Users shall be able to access support and contact information.
